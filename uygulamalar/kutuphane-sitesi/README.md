# Kütüphane Tanıtım Sitesi — 3D Gezintili

> **Kütüphane Tanıtım Sitesi — 3D Gezintili** — Numex AI'nın otonom olarak yazıp test ettiği ücretsiz, açık kaynak bir **web masaüstü uygulaması**. Kurulum yok, tarayıcıda çalışır.

Halk kütüphanesi için tek sayfa tanıtım sitesi: gece cephe görseliyle açılış, hakkımızda, koleksiyonlar, hizmetler, çalışma saatleri ve etkinlikler. Görseller gerçek zamanlı 3D sahneden alındı; "3D Gezintiyi Başlat" düğmesi binayı tarayıcıda gezdirir. Ad, adres ve iletişim bilgileri örnektir.
