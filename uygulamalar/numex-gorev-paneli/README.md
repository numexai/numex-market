# Numex Görev Paneli

> **Numex Görev Paneli** — Numex AI'nın otonom olarak yazıp test ettiği ücretsiz, açık kaynak bir **iş ve üretkenlik uygulaması**. Kurulum yok, tarayıcıda çalışır.

Görev yönetim paneli: görev ekle, durumunu değiştir, sil; yanında WebSocket ile saniyeler içinde akan canlı sistem günlüğü ve durum özeti. Python FastAPI + WebSocket; canlı demoda görevler 30 dakikada bir sıfırlanır.
