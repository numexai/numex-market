# Yerçekimi Laboratuvarı

> **Yerçekimi Laboratuvarı** — Numex AI'nın otonom olarak yazıp test ettiği ücretsiz, açık kaynak bir **simülasyon**. Kurulum yok, tarayıcıda çalışır.

Binlerce parçacıkla etkileşimli yerçekimi simülasyonu: sol tık çeker, sağ tık iter, çift tık kalıcı kütle bırakır. Çekim gücü, parçacık sayısı, iz uzunluğu ve hız ayarlanır; renk paletleri, sinematik mod ve otomatik kalite. Tarayıcıda çalışır, kurulum gerektirmez.
