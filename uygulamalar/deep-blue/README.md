# Deep Blue — Okyanusun karanlığında yaşayan ışıklar

> **Deep Blue — Okyanusun karanlığında yaşayan ışıklar** — Numex AI'nın otonom olarak yazıp test ettiği ücretsiz, açık kaynak bir **simülasyon**. Kurulum yok, tarayıcıda çalışır.

Tamamen kodla üretilmiş 3B denizanası akvaryumu: kendi ritminde atan çan gövdeleri, dalgalanan dokunaçlar, yukarı süzülen biyolüminesans parçacıklar ve ışık huzmeleri. Denizanasına dokununca rengi değişir; ışık, hız ve sayı ayarı, sinematik tur. Tarayıcıda çalışır, kurulum gerektirmez.
