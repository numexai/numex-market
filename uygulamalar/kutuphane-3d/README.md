# Kütüphane 3D — Gezilebilir Halk Kütüphanesi

> **Kütüphane 3D — Gezilebilir Halk Kütüphanesi** — Numex AI'nın otonom olarak yazıp test ettiği ücretsiz, açık kaynak bir **simülasyon**. Kurulum yok, tarayıcıda çalışır.

Tarayıcıda gezilebilen iki katlı halk kütüphanesi: 12 kitaplıkta 8.573 kitap, okuma salonları, danışma bankosu, bilgisayar alanı, balkonlu ikinci kat. Dış/iç kamera, WASD ile yürüyüş, gece/gündüz, kat ve çatı gizleme, kitaplığa tıklayınca kategori kartı.
