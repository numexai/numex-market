# Mahalle Fırını Sipariş Takibi

> **Mahalle Fırını Sipariş Takibi** — Numex AI'nın otonom olarak yazıp test ettiği ücretsiz, açık kaynak bir **araç**. Kurulum yok, tarayıcıda çalışır.

Fırın için sipariş takibi: simit, poğaça, açma, ekmek; müşteri adıyla sipariş, hazır/teslim işareti, gün sonu cirosu. Veriler tarayıcıda saklanır, telefonda da rahat kullanılır.
